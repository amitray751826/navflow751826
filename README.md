# NovaFlow – Responsive Landing Page

A modern and responsive landing page built using **HTML5, CSS3, and Vanilla JavaScript**.

## 🚀 Features

* Fully responsive design
* Semantic HTML5 structure
* Flexbox & CSS Grid
* Responsive hamburger navigation
* Hero section with CTA
* Feature cards
* About & statistics section
* Responsive footer
* Smooth scrolling
* Clean and commented code

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## ▶️ How to Run

1. Download and extract the project ZIP.
2. Open the folder in **VS Code**.
3. Open `index.html`.
4. Run with **Live Server** or open `index.html` directly in a browser.
